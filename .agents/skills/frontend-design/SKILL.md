# Frontend Design Skill

## Key Focus Areas
- **Visual Hierarchy**: Distinct font weight contrast, structural margins, clear call-to-actions.
- **Component Consistency**: Standardized primary, secondary, and ghost buttons, badges, and card containers.
- **Responsive Grid**: Flexbox and CSS Grid layout structures supporting screens from 320px to 4K displays.
