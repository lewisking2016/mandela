# Redesign Existing Projects Skill

## Workflow
1. **Audit Existing Stack**: Identify UI inconsistencies, performance bottlenecks, accessibility gaps, and security flaws.
2. **Design Tokens**: Establish clear color palettes, typography scales, spacing tokens, and shadow system.
3. **Component Refactoring**: Modernize layouts into clean, semantic, accessible HTML5 elements.
4. **Interactive Enhancement**: Add subtle micro-animations (GSAP/CSS transitions) without compromising rendering performance.
5. **Backwards Compatibility**: Retain core business logic, fallback logging, and legacy route structures while upgrading interfaces.
