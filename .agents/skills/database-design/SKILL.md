# Database Design Skill

## Principles
- **Schema Normalization**: Maintain proper third normal form (3NF) where appropriate.
- **Indexing**: Add indexes on frequently queried columns (`email`, `created_at`, `service_type`).
- **Data Integrity**: Enforce non-null constraints, strict data types (`VARCHAR`, `TIMESTAMP`), and UTF8MB4 encoding.
