# Frontend Development Guidelines Skill

## Guidelines
- **Accessibility**: Include alt attributes, ARIA attributes (`aria-expanded`, `aria-label`), keyboard navigation support.
- **CSS Architecture**: Prefer CSS custom properties, avoid inline styles where possible, minimize layout thrashing.
- **JS Clean Code**: Avoid global variable pollution, use strict mode or ES modules, handle asynchronous errors gracefully.
