# Next.js App Router Patterns Skill

## Core Concepts
- Use React Server Components (RSC) for data fetching and heavy rendering.
- Keep Client Components (`'use client'`) small and focused on interactivity.
- Leverage Route Handlers and Server Actions for form submissions and mutations.
