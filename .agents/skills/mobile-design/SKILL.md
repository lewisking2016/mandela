# Mobile Design Skill

## Guidelines
1. **Touch Targets**: Minimum 44x44px for interactive elements on mobile viewports.
2. **Fluid Layouts**: Use relative units (rem, %, clamp, vh/vw) over fixed pixel widths.
3. **Mobile Navigation**: Collapsible, accessible drawer/overlay menus with keyboard and tap controls.
4. **Performance**: Optimize images, lazy-load offscreen media, and limit heavy CSS filters on low-power devices.
