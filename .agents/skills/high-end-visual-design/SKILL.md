# High-End Visual Design Skill

## Standards
- **Color Palette**: Deep dark modes, vibrant accent colors, HSL-based dynamic gradients.
- **Visual Polish**: Subtle backdrop-filter glassmorphism, refined multi-layered box shadows, sleek borders.
- **Typography**: Modern variable fonts (Inter, Plus Jakarta Sans, Outfit), tight line-heights, letter-spacing adjustments.
- **Micro-Interactions**: Smooth hover elevations, interactive button glow effects, animated gradient borders.
